Kid mode

One navigation stack under the home screen. A parent does the setup steps here; the kid mostly sees the Screen Time section and asks for more time.

The block page

  • Apple draws it over a blocked app with ScreenThyme's text (ThymeShield). OK closes the app.
  • Its menu's One more minute lets the app through, once a day per app, without opening ScreenThyme.
  • Ask for more time saves what was blocked. On iOS 26.5 and later it opens ScreenThyme, which shows the sheet over Home. On earlier iOS it just closes, and the sheet appears the next time the kid opens the app.

Same screen, two ways in

  • Match by screenshot: from Home's Apps for Screen Time section, and from Debug.
  • Ask for more time: from the Screen Time section's button, and from the block page.
  • Pushes from the Ask sheet stay inside the sheet, which has its own stack; Done closes it.

Not drawn

  • Buttons that act in place: Upload now, Start monitoring, Re-register, Stop monitoring, the One more minute stepper.
  • Pull to refresh, Debug's day arrows, and the timeline's inline block detail.
  • The app-wide “ScreenThyme” message alert, which can show over any screen.
  • Joining a family: the kid opens a parent's invite link from Messages or Mail. No screen changes.

Parent mode

Three tabs, each with its own navigation stack. Most of the depth is under one kid's Rules and health, where Screen Time edits what the kid's phone enforces.

Same screen, two ways in

  • ‹kid› (Rules and health): from a kid's day, and from Settings › Kids.
  • Change history: from a kid's day, and from Screen Time.
  • ‹list name› item picker: inside the Downtime, App Limit and Group sheets, and on the main stack from Always Allowed and Blocked.
  • Raw usage is the same view the kid's Debug uses, fed from the synced records.

In place, no new screen

  • Alerts: requests are answered right in the list (Approve, Other ▾, Decline), and the kid filter is a menu.
  • Screen Time: Save and Revert in the toolbar, swipe to delete a window, limit or group.
  • Add rule ▾ is a menu of seven presets; each opens the rule sheet.
  • Timeline: zoom buttons and the Options ▾ menu.

Not drawn

  • Create family, Ping now, Re-install push subscriptions, and pull to refresh.
  • Content & Privacy's rating pickers and the Websites mode, which are menus. The mode decides which website lists appear.
  • Tapping an alert notification opens the app where it was; there are no deep links.
